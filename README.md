# مصاريفي

تطبيق أندرويد شخصي بيقرا رسايل البنوك (الراجحي، الأهلي، الإنماء، STC Pay / STC Bank، urpay) ويحسب مصاريفك.
كل حاجة بتحصل على الموبايل — مفيش سيرفر ولا إنترنت.

## تطلع الـ APK
1. دوس دبل كليك على `build-apk.bat`
2. أول مرة هياخد كام دقيقة (بينزّل الحاجات المطلوبة)
3. هيفتحلك الفولدر وفيه `masareef.apk` — ابعته لموبايلك ونزّله
   (لو الموبايل اعترض: اسمح بـ "تثبيت تطبيقات من مصادر غير معروفة")
4. افتح التطبيق ووافق على إذن قراية الرسايل

محتاج على الكمبيوتر: Node.js و Android Studio (متسطّب ومتفتح مرة واحدة على الأقل).

## كل حاجة بالراتب
الشهر في التطبيق = من نزول الراتب للراتب اللي بعده. النسب كلها من الراتب، والحدود بتبدأ من جديد مع كل راتب.

## حدود البنود والإشعارات
من الإعدادات ← حدود البنود: حط حد شهري لأي بند. أول ما توصل رسالة شراء من البنك (حتى والتطبيق مقفول) بيتحسب المبلغ على البند، ولو وصلت ٨٠٪ أو عدّيت الحد هيجيلك إشعار.

## تعديل الكود
- `src/lib/parser.js` — فهم رسايل البنوك
- `src/lib/categories.js` — البنود وقواعد التصنيف
- `android/.../SmsReaderPlugin.java` — قراية الرسايل من أندرويد
- بعد أي تعديل: `npm run sync` وبعدين `build-apk.bat`
- تجربة في المتصفح: `npm run dev` واستورد ملف XML من الإعدادات

## آيفون
- **نسخة الويب (PWA):** https://eslamgmalelsayed.github.io/masareef/ — افتحها في سفاري ← مشاركة ← إضافة إلى الشاشة الرئيسية
- **التطبيق الكامل (SideStore):** ضيف المصدر `https://github.com/eslamgmalelsayed/masareef/releases/download/ios-latest/apps.json`


## الاختبارات

قبل أي نسخة (أندرويد / آيفون / الويب) السيرفر بيشغّل الاختبارات، ولو أي اختبار فشل **مفيش نسخة بتنزل**.

- `npm test` — قراية رسايل البنوك (رسايل وهمية في `tests/fixtures/sms.json`) + الحسابات: الاشتراكات، الأقساط، الكريدت، الديون، الحدود، "تقدر تصرف/يوم".
- `android/app/src/test` — الجزء الأصلي اللي بيبعت التنبيهات والتطبيق مقفول لازم يطلع نفس المبلغ والتاجر زي الـ JS (`node scripts/make-java-fixtures.mjs` بيحضّر الملف).

لو بنك غيّر شكل رسايله: ضيف رسالة وهمية بنفس الشكل في `tests/fixtures/sms.json` (من غير أرقام أو أسماء حقيقية) ومعاها النتيجة المتوقعة.
